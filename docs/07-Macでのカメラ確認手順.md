# MacBook で、カメラと OBS のつながりを確かめる（段階 1）

費用 0 円・AWS なしで、MacBook の中だけで試します。本物の OBS とカメラを使い、IVS（映像の配信）だけはアプリの代役で済ませます。

| 確かめること | この手順で分かるか |
|---|---|
| 各カメラ（スマホ・無線・USB）が OBS に映る | 分かる |
| 配信エージェントが OBS につながる | 分かる |
| 進行コンソールのボタンで、カメラが切り替わる | 分かる |
| OBS の出力が 960×720 に自動でそろう | 分かる |
| 参加者のスマホに映像が届く・映像の遅れ | 分からない（段階 2 で確かめる） |

かかる時間の目安: 初回 1〜2 時間（入れるもの 30 分、カメラごとの設定 10〜20 分ずつ）。

---

## 1. 入れるもの（初回だけ）

### 1.1 開発用の道具（Xcode コマンドライン ツール）

「ターミナル」（アプリケーション → ユーティリティ）を開いて、次を実行します。すでに入っていれば「already installed」と出ます。

```bash
xcode-select --install
```

### 1.2 Node.js 22

1. https://nodejs.org/ を開き、**22 の LTS** の macOS 用インストーラ（.pkg）を入れます。
2. ターミナルで確かめます。`v22.` で始まれば OK です。

```bash
node -v
```

### 1.3 OBS Studio

1. https://obsproject.com/ から macOS 用を入れます（MacBook の CPU に合うもの。Apple シリコンなら Apple Silicon 版）。
2. 初めて起動したときの「自動構成ウィザード」は、閉じてかまいません。
3. **カメラの許可**: 「システム設定 → プライバシーとセキュリティ → カメラ」で、OBS をオンにします（OBS が初めてカメラを使うときに聞かれた場合は「許可」）。

### 1.4 アプリ（このリポジトリ）

ターミナルで、次を順に実行します。

```bash
cd ~
```

```bash
git clone -b claude/vigilant-wozniak-jhrqv6 https://github.com/Peyangpiece/auction-poc.git
```

```bash
cd ~/auction-poc && npm ci && (cd agent && npm ci)
```

- エラーで止まったら、表示された最後の 20 行ほどを控えてください。

## 2. OBS の設定（初回だけ）

OBS のメニューの名前は、版によって少し違うことがあります。

### 2.1 WebSocket（配信エージェントがつなぐ口）

1. メニューの「**ツール → WebSocket サーバー設定**」を開きます。
2. 「**WebSocket サーバーを有効にする**」にチェックを入れます。
3. 「**認証を有効にする**」にチェックを入れ、パスワードを決めます（「接続情報を表示」で確かめられます）。ポートは **4455** のままにします。
4. 「OK」で閉じます。このパスワードは、4.2 で使います。

### 2.2 映像の大きさ

1. 「**OBS → 設定**」（⌘ + ,）→「**映像**」を開きます。
2. 「**基本（キャンバス）解像度**」に **1440x1080** と入れます（4:3 にする）。
3. 「出力（スケーリング）解像度」は、そのままでかまいません。配信エージェントが 960×720 にそろえます。
4. 「OK」で閉じます。

### 2.3 カメラごとのシーン

カメラ 1 台ごとに、シーンを 1 つ作ります。**名前は「カメラ」で始めます。**

1. 画面の左下の「**シーン**」の欄の「**＋**」を押し、名前を入れます（例: `カメラ: Mac内蔵`）。
2. そのシーンを選んだまま、「**ソース**」の欄の「**＋**」→「**映像キャプチャデバイス**」を選び、カメラを選びます。
3. 映像を右クリック →「**変換 → 画面に合わせる**」で、画面いっぱいに合わせます。
4. カメラの数だけ繰り返します。

カメラの種類ごとの選び方:

| カメラ | Mac へのつなぎ方 | 2 で選ぶもの |
|---|---|---|
| Mac の内蔵カメラ（まず、これで試す） | なし | 「FaceTime HD カメラ」など |
| iPhone | **連係カメラ**: Mac と iPhone を同じ Apple アカウントにし、Wi-Fi と Bluetooth をオンにして、iPhone を近くに固定する（使える機種・OS の条件は、Apple のサポートページで確かめる） | iPhone の名前のカメラ |
| Android | スマホを Web カメラにするアプリ（例: Camo）を、スマホと Mac の両方に入れる。USB でつなぐと途切れにくい【アプリの対応は、入れる前に確かめる】 | アプリのカメラ |
| USB の Web カメラ | Mac の USB（USB-C）につなぐ。USB-A のカメラは変換アダプタを使う | カメラの名前 |
| ビデオカメラ・一眼（HDMI） | HDMI→USB のキャプチャ機器を通してつなぐ | キャプチャ機器の名前 |
| ワイヤレス映像伝送機（HDMI） | 受信機の HDMI を、HDMI→USB のキャプチャ機器でつなぐ | キャプチャ機器の名前 |
| Wi-Fi のネットワークカメラ（RTSP） | カメラと Mac を同じ Wi-Fi・LAN につなぐ | 2 で「映像キャプチャデバイス」ではなく「**メディアソース**」を選び、「ローカルファイル」を外して、入力にカメラの RTSP の URL を入れる（URL はカメラの説明書） |

- 「カメラ」で始まらないシーン（例: `休憩の画面`）を作っておくと、進行コンソールに出ないことも確かめられます。

## 3. 毎回の起動（ターミナルの 3 つのタブ）

ターミナルで ⌘ + T を押すと、タブが増えます。**OBS は先に起動しておきます。**

### タブ 1: 入札サーバー

初回だけ、テスト用の合言葉を作ります。

```bash
cd ~/auction-poc && node tools/seed.js --members 3
```

毎回、サーバーを起動します（IVS は代役）。このタブは開いたままにします。

```bash
cd ~/auction-poc && POC_IVS_MODE=mock node server/src/index.js
```

### タブ 2: 配信エージェント

`ここにパスワード` を、2.1 で決めた OBS の WebSocket のパスワードに置き換えて実行します。このタブも開いたままにします。

```bash
cd ~/auction-poc/agent && AGENT_SERVER_URL=ws://127.0.0.1:8080/agent AGENT_TOKEN="$(node -p "require('../data/tokens.json').agent")" OBS_PASSWORD='ここにパスワード' node src/agent.js
```

- `[agent] obs_connected` と `[agent] server_connected` が出れば、つながっています。
- `obs_connect_failed` が出るときは、OBS が起動しているか、2.1 のパスワードとポート（4455）が合っているかを確かめます。

### タブ 3: 進行コンソールを開く

```bash
cd ~/auction-poc && open "http://127.0.0.1:8080/console.html?t=$(node -p "require('./data/tokens.json').auctioneer")"
```

## 4. 確かめること（チェックリスト）

進行コンソールの右側の「**配信**」の欄を見ます。

| # | やること | よい状態 | 結果 |
|---|---|---|---|
| 1 | 配信の欄を見る | 「配信エージェント: 接続中」 | |
| 2 | 同じ欄の「映像の大きさ」 | **960×720**。OBS の「設定 → 映像」の出力解像度も 960x720 に変わっている | |
| 3 | 「カメラ」のボタン | OBS で作った「カメラ…」のシーンが、OBS と同じ順で並ぶ（「カメラ: 」は省いて出る）。「休憩の画面」などは出ない | |
| 4 | カメラのボタンを順に押す | OBS の画面（番組）が、そのカメラに切り替わる。押したボタンが塗りつぶされる | |
| 5 | OBS の画面で、シーンを手で切り替える | 進行コンソールの塗りつぶしも、追って変わる | |
| 6 | OBS で新しく「カメラ: テスト」のシーンを足す | 進行コンソールに、ボタンが増える | |
| 7 | 各カメラの映像 | ゆがみ・黒い帯がない。動きがカクつかない（OBS の画面で目で見る） | |
| 8 | OBS を終了する | 進行コンソールのカメラの欄が消える。OBS をもう一度起動すると、数秒で戻る | |
| 9 | 基本解像度を 1920x1080 に変える（試したら 1440x1080 に戻す） | 進行コンソールに「基本解像度の縦横の比が違う」という注意が出る。出力は変わらない | |

- **この段階では、品の「開始」と「配信を開始」は押さないでください。** OBS に配信先（IVS）を入れていないため、OBS 側で配信の開始に失敗します（段階 2 で確かめます）。
- 1 と 3 で困ったら、タブ 2 の表示（`[agent] …`）を控えてください。

---

## 5. 終わるとき

1. タブ 1 とタブ 2 で、**control + C** を押して止めます。
2. OBS は、そのまま終了してかまいません。
3. 次からは、「3. 毎回の起動」だけを行います（タブ 1 の `seed.js` は不要）。

テストのデータをすべて消して、やり直したいとき（合言葉も作り直しになります）:

```bash
cd ~/auction-poc && rm -rf data
```

---

## 6. 結果の伝え方

4 のチェックリストの「結果」（OK・NG）と、NG だった項目では次を伝えてください。

- どのカメラか（機種名）、どうつないだか
- 進行コンソールと OBS の画面のスクリーンショット（⌘ + Shift + 4）
- タブ 2 の `[agent] …` の表示

`data/tokens.json` の中身（合言葉）は、送らないでください。
