# 本番運用を想定した徹底評価（令和の競り）

- 評価日: 2026-11-19
- 対象: ブランチ `claude/vigilant-wozniak-jhrqv6`（HEAD 3d421d9。いまの本番と同じ版）
- 想定: 1回8時間の競り、オンライン参加 数十〜300人、月4回、実際の売買・請求・入金。Cloudflare（コンテナ1台）＋R2
- 方法: 4つの観点を、それぞれ手元でサーバーを動かして検証しました。観点は、安全性と個人情報、運用と信頼性、業務とお金の正しさ、全画面の使いやすさです。**本番サイトには一切触れていません。**
  - 「確認済み」は、手元で再現したものか、測ったものです。
  - 「推測」は、コードや外部の仕様から判断したものです。
  - 重大な指摘は、まとめ役がもう一度再現して確かめました。
- 再現に使ったスクリプトと撮った画像は、作業用のフォルダ（eval-sec・eval-ops・eval-biz・eval-ux）にあります。リポジトリには入れていません。

---

## 判定: **いまのままでは、一般の会員に公開できない**

**一般の会員に公開する前に、必ず片づけるもの（9件）**
- 安全の穴が1件。いまの本番そのものにあります（A1）。
- 配る作業が競りを壊しうる件（A2）。
- 外部の準備が2件。メールの送信の準備（A3）と、規約類の文面（A4）です。
- 業務の流れの欠陥が2件。開催の終了に関わるものです（A5・A6）。
- データの消失・監視・復元の不備が3件（A7〜A9）。

**よくできている点**
- 入札の速さは十分です。300人が毎秒50件入札しても、受理の応答は9ミリ秒（p95）でした。
- 落札・請求書の金額と、PDF の行・合計は正確でした。
- 他人の情報や請求書は見られませんでした。
- 公開しているリポジトリに、秘密の値や本物の個人情報はありませんでした。
- 縦向きのスマホでの競りの画面、締めの確かめ、会場モニター、暗い配色も良い出来です。

つまり、競りの仕組みそのものは本番に耐えます。足りないのは、その周り（運用の準備・終了の処理・お金の例外の処理・本番の設定）です。

## C. 早めに直す（抜粋）

- **業務**
  - 違約金・遅延損害金を、同じ明細に何度でも出せる。
  - 開催終了のあとに受け取った現金を、現金として記録できない。
  - 入金日を入れられない（操作日が入金日になる）。
  - 打診と承諾のあいだに買歩銭の率を変えると、請求額が変わる。
  - 解除しても、請求書の合計表示が直らない。
  - 管理画面の一覧に件数の上限がある（1000件・500件）。
- **安全**
  - 停止した会員がコメントできる。
  - 退会・却下の後も、個人情報（パスワードのハッシュを含む）が無期限に残る。
  - 監査ログに残らない操作がある（ログイン、会員一覧・PDF・Excel の閲覧など）。
  - 電話番号の先取り。
  - ログイン ID の推測による締め出し。
- **運用**
  - 測定の記録が本番でも詳しすぎる（11分で326MB）。
  - 「30分通信がないと止まる」への手当てが未検証（スマホのスリープ中は効かない）。
  - 前の版に戻す手順がない。
  - 再接続の間隔をばらしていない。
  - workers.dev のまま（独自ドメインにする）。
- **画面**
  - 本番では使わない SMS を、ログインの画面で案内している。
  - 競りの最中に「お支払いの確認へ」が出て、競りの画面を離れさせる。
  - 回線が切れたとき、古い価格が読めてしまう。
  - 受付のスマホのタブが小さい。
  - マイページの請求書に振込先が出ない。

## D. 軽微（抜粋）

- サーバー側に入札額の上限がない（110,000,000円も受理される）。
- 取りやめのあとも、うりきりのランプが残る（意図か要確認）。
- 規約の下書きとシステムの動きのずれ（送料の単位、受け取り期限の起点）。
- 言葉のゆれ（開始値／開始価格 など）。
- 44px 未満の押し場所。
- HSTS がない。
- 応答時間の差で、登録の有無を調べられる。

## E. 問題がなかったもの（確かめて、良かった点）

| 観点 | 結果 |
|---|---|
| 入札の性能 | 300接続・毎秒50件・CPU を約半分にしても、受理の応答は p95 9.1ms、メモリ138MB 以下。11分の連続運転でも劣化なし |
| 競りの正しさ | うりきり（79・89章）、締めと同時の入札、代理入札、取りやめ、再起動からの復旧（受付中→中断、入札とうりきりは残る）が正しく動いた |
| お金の計算 | PDF の行・小計・消費税（内税、1通に1回の切り捨て）・合計がデータベースと一致。同時の精算・同時の消し込みは片方だけが通った |
| 権限 | 他人の請求書・個人情報は見えない。オークショニアの越権の11操作はすべて断られた。各スタッフの役割の境目も守られている |

| 合言葉 | 受付の QR・配信停止のリンク・配信エージェントの合言葉は、推測できない長さ |
| 公開リポジトリ | 履歴の全体に、秘密の値・本物の個人情報・口座はない |
| 画面 | 縦向きのスマホの競りの画面、締めの確かめの文、会場モニター、暗い配色 |
