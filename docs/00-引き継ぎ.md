## 1. これは何か

「令和の競り」は、会場とオンラインで同時に参加できる、ライブのせり（オークション）のアプリです。

- **サーバー**
  - Node 22 で動きます（`server/src/`）。
  - WebSocket で入札を受けます。
  - データベースは SQLite（better-sqlite3）です。
- **画面**: `web/`（HTML と素の JavaScript）
  - `bidder.html`: 参加者の入札画面
  - `caller.html`: オークショニア（スマホ）
  - `console.html`: 進行コンソール（PC）
  - `monitor.html`: 会場の表示
  - `staff.html`: 管理画面（主催者管理者・受付係ほか）
  - `mypage.html`: 会員のマイページ
- **本番**
  - Cloudflare Workers と Containers の上で、コンテナ 1 台で動きます。入口は `cloudflare/worker.js` です。
  - データは R2 に保存します（`server/src/persist.js`。約 2 秒ごと、gzip、日ごとの控え）。
- **映像**
  - 配信用 PC の OBS から、Amazon IVS へ送ります。
  - 配信エージェント（`agent/`）が OBS を操作します。「カメラ」で始まるシーンを切り替え、出力を 960×720 にそろえます。
- **役割**
  - スタッフ: admin（主催者管理者）・auctioneer（進行役）・caller（オークショニア）・reception（受付係）・operator（開発運営者）
  - 会員: 個人（b2c）・法人（b2b）

## 6. 動かし方・確かめ方

```bash
npm ci

npm run test:e2e    # 画面の通しの確かめ（Playwright）
npm run test:a11y   # アクセシビリティ
```
