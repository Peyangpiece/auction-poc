# 技術の選定・構成・作業計画・未決3点

引き継ぎ書の「最初の返信でしてほしいこと」の3点です。
今回は「PoC を作成」という指示を受けて、了承を待たずに下の案で実装まで進めました。
どれも差し替えられる作りにしてあるので、変えたいものがあれば指摘してください。

## 1. 技術の選定案と理由

| 対象 | 選んだもの | 理由 | 差し替えるときの影響 |
|---|---|---|---|
| 言語・実行環境 | Node.js 22（JavaScript、ES Modules） | サーバー・配信エージェント・負荷のプログラム・画面を1つの言語で書ける。配信エージェントを Windows と macOS のどちらでも同じコードで動かせる（POC-OQ-01 が未定でも作れる）。1スレッドで順に処理する作りが、「受付連番の順に1件ずつ」という要件（FR-BID-004）とそのまま合う | 本番で型が欲しければ TypeScript に移す（構造は変えずに済む） |
| WebSocket | `ws` | Node.js で最も使われている実装で、余計な層がない。再接続や部屋分けを自前の決まり（FR-UI-001）で作るので、Socket.IO の独自の再接続は要らない | 小さい |
| データベース | SQLite（`better-sqlite3`、WAL、`synchronous=FULL`） | サーバーが Lightsail 1台・プロセス1つという決定に合う。別のデータベースのプロセスが要らず、2GB のメモリを圧迫しない。API が同期なので、入札1件の「判定 → 書き込み → 応答」の途中に別の入札が割り込めず、順番の正しさをコードの形で保証できる。コミットごとに fsync するので、「書き込みが終わってから受理と返す」（NFR-REL-001）を満たす | 本番で PostgreSQL にする場合、書き換えるのは `server/src/db.js` と、`auction.js` のうち書き込みを呼ぶ部分。そのときは「処理の途中で割り込まれない」ことを、ロットごとの列で明示的に守る必要がある |
| 配信エージェント → OBS | `obs-websocket-js` 5.x | obs-websocket 5.x の公式の JavaScript クライアント | 小さい |
| IVS の状態 | `@aws-sdk/client-ivs`（GetStream）と、EventBridge の API destination → サーバーの HTTPS の受け口 | POC-IVS-001 の (a)(b) を両方作って比べるため。Lightsail は AWS のイベントを直接受けられないので、(b) は HTTPS の POST で受ける | (b) をやめて (a) だけにするのは設定1つ |
| 負荷をかける道具 | 自作（`tools/load.js`） | 測りたいのが「端末ごとの、価格の更新が届いた時刻」で、時刻合わせ（POC-SRV-006）と送り返し（POC-SRV-008）を本物の端末と同じ手順で行う必要がある。k6 などの既製の道具では、この手順を組み込みにくい | — |
| 回線の劣化の模擬 | Linux の `tc netem`（`tools/netem.sh`） | PoC 仕様書 P2-7 の指定どおり | — |
| 集計 | 自作（`tools/aggregate.js`） | 生の記録（NDJSON）から p95 などを計算する（PoC 仕様書 6章） | — |
| HTTPS | Caddy（証明書を自動で取る） | スマホで「画面を消さない機能」などを試すには https のページが要る | Nginx でもよい |
| PDF・Excel を作るライブラリ | **PoC では選ばない**（PoC 仕様書 2.2 で請求書は対象外）。本番の候補: PDF は `pdfkit`＋日本語フォントの埋め込み、Excel は `exceljs` | どちらも Node.js だけで動き、外部のプログラムが要らない。日本語フォントを埋め込める（FR-INV-007） | 本番の手順6に着手する前に、試作して確かめてから決める |

## 3. PoC を始める前に決める3点（POC-OQ-01〜03）

回答が空欄だったので、PoC 仕様書の推奨で進めてよいかの確認です。実物での測定を始める前に答えをください。

| ID | 論点 | 回答が空欄のときに使う推奨 | 今の実装への影響 |
|---|---|---|---|
| POC-OQ-01 | 配信用PCの OS | 本番で使うものに合わせる（どちらかは発注者しか決められない） | なし。エージェントは Windows と macOS の両方で動く作り。ただし P1 の数値は、測った OS のものとして報告する |

| POC-OQ-03 | 実機の機種 | 2〜3年前の iPhone と Android を1台ずつ | なし |

| ID | 論点 | 推奨 | 理由 |
