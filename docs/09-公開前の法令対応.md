# 正式公開の前の法令対応（A-1〜3）

正式に公開する前に、法律の面で済ませることをまとめた表です。

**この文書は、弁護士・行政書士・警察署の確認の代わりにはなりません。** 法律の判断は、専門家と管轄の役所で確かめてください。書くにあたって、公的機関（総務省・警察）の資料を検索で調べました。ただし、この開発環境からは役所のページを直接開けなかったため、検索結果の要約に頼っている箇所があります。その箇所には【要確認】を付けています。

---

## 1. 古物営業法（中古品をネットで扱う）

### 1.1 求められること（調べた範囲）

| 項目 | 内容 | 根拠（調べた資料） |
|---|---|---|
| 古物商の許可 | 中古品を売り買いする事業には、営業所のある都道府県の公安委員会（窓口は警察署）の許可が要る | 各県警の案内 |
| URL の届出 | ホームページを使って古物の取引をするときは、その URL を届け出る | 古物営業法 第5条第1項第6号・第7条第1項（茨城県警の案内による） |
| サイトへの表示 | 取り扱う古物と一緒に、**氏名または名称・許可をした公安委員会の名称・許可証の番号**を、ホームページに表示する | 古物営業法 第12条第2項（長野県警の案内による） |
| 競り売りの届出 | ホームページを使って、相手と顔を合わせずに競り売りをするときは、**競り売りの3日前までに** URL などを届け出る（インターネットオークションへの出品は例外、とされている） | 神奈川県警の案内による【要確認: 条文と、この競りが当たるか】 |

### 1.2 この事業で、まず確かめること【要確認: 警察署（生活安全課）】

1. **どの許可・届出が要るか**：品物の出どころで変わります。
   - 自社の品を売る → 古物商の許可と URL の届出。
   - ほかの事業者から預かった品を競りにかける → 委託の扱い。
   - 古物商どうしが売り買いする市場を開く → 古物市場主の許可。
   - 個人どうしの売り買いを取り次ぐ → 古物競りあっせん業の届出。
2. **開催ごとの「競り売りの届出」が要るか**：この競りは、会場とネットを同時に使う、ライブの競り売りです。開催ごとに3日前までの届出が要るかを確かめます。要るなら、開催を公開する前の手順に組み込みます（アプリでは、公開の前に注意を出せます）。
3. **表示する場所**：いまの表示で足りるかを確かめます（下の 1.3）。
4. **本人確認・取引の記録**：中古品を買い取る場面では、相手の確認と帳簿への記録が要ります。この競りで「買い取り」に当たる取引があるかを確かめます。

### 1.3 アプリの対応（今回、足したもの）

- 管理画面の「設定」に、**「古物商の許可」**の欄を足しました。「〇〇県公安委員会　第000000000000号」の形で入れます。
- 入れると、主催者の名称と一緒に、**すべてのページの下の欄**と、**競りの画面**（品物を見せる画面）の下に出ます。
- 入れるまでは、管理画面の「公開の前に入れておく項目」に出し続けます。

## 2. 特定電子メール法（開催のお知らせメール）

### 2.1 求められること（調べた範囲）

| 項目 | 内容 | 根拠（調べた資料） |
|---|---|---|
| 事前の同意 | 広告・宣伝のメールは、あらかじめ送信に同意した人にだけ送れる（取引関係にある人など、一部の例外がある） | 総務省の資料 |
| 同意の取り方 | 送ることを、分かりやすく示して同意を取る。目立たない色の文字や、長くスクロールしないと気づけない場所に書くのは、適切とは言えない。**同意の欄は、最初はチェックを外しておくこと（デフォルトオフ）が推奨**されている | 総務省のガイドライン（改正の案の概要） |
| 同意の記録 | 同意を受けたことの記録（いつ・どのように）を保存する | 総務省の資料【要確認: 保存期間】 |
| 表示 | 送信者の氏名または名称、受信を拒否するためのメールアドレスまたは URL、受信を拒否できる旨（その URL の前か後に）、住所、苦情・問い合わせの連絡先 | 総務省の資料・施行規則 |
| 拒否のあと | 受信の拒否を受けたら、以後は送らない | 同上 |

### 2.2 アプリの対応（今回、足したもの・直したもの）

| 求められること | 対応 |
|---|---|
| 事前の同意 | 会員登録の画面に「開催のお知らせメールを受け取る」の欄を足した。**最初はチェックを外してある**。チェックした人にだけ送る |
| 同意の記録 | 同意した時刻と、どこで同意したか（登録の画面・マイページ）をデータベースに残す。切り替えは監査ログにも残る |
| 同意の記録がない人 | これまでの版で「最初から受け取る」扱いだった会員のうち、同意の記録がない人には送らない（本人がマイページで受け取るに切り替えると、送る） |
| 受信の拒否 | メールの本文に「受信を止める（配信を停止する）ときは、次のページから手続きできます（ログインは不要です）」と書き、そのすぐあとに、**ログインせずに止められるページの URL** を載せた。マイページの切り替えも、これまでどおり使える |
| 送信者の表示 | 署名に、主催者の名称・住所・電話・メールを出す（「設定」に入れたもの。**入れておくこと**） |

- 止めるのは、ページの「配信を止める」ボタンを押したときだけにしました。迷惑メール対策の仕組みが、メールのリンクを先に開くことがあるためです。
- お支払い・落札など、取引に必要な連絡は、この切り替えに関係なく送ります。

### 2.3 確かめること【要確認: 弁護士】

- 開催のお知らせが「広告・宣伝のメール」に当たるか（当たる前提で作りました）。
- 同意の記録の保存期間。
- 会員登録の規約の文面に、お知らせメールのことを書くか（下書きには書きました）。

## 3. 特定商取引法（通信販売としての表示）

### 3.1 求められること（調べた範囲）

インターネットで物を売るのは通信販売に当たり、広告（サイト）に決まった事項の表示が要ります。消費者庁の解説では、表示事項は約15項目とされています。主なものは次のとおりです。

- 販売価格と送料
- 代金の支払いの時期と方法
- 商品の引き渡しの時期
- 申し込みの期間に関する定めがあるときは、その内容
- 契約の申し込みの撤回・解除に関すること（**返品特約**）
- 事業者の氏名・住所・電話番号
- 契約不適合（品物の不具合）のときの責任についての定めがあるときは、その内容

連絡先は、サイトの冒頭から「特定商取引法に基づく表示」のリンクでたどれれば足りる、と整理されています（消費者庁の解説を紹介した記事による）。

### 3.2 この事業で確かめること【要確認: 弁護士】

1. **最終確認画面の表示**：入札（申し込み）の前の画面に表示すべき事項があるか。通信販売の申し込みの最終確認画面には、分量・価格・支払いと引き渡しの時期・撤回や解除のことなどを表示する決まりがあります。ライブの競りの入札が、これに当たるかを確かめます。いまは、参加手続きの画面に買歩銭・支払方法・受け取り方法・規約へのリンクを出しています。
2. **返品特約**：中古品の現状渡しで、返品を受けないとする場合の書き方。
3. **事業者どうしの取引**：法人の会員（事業者どうしの取引）には、特定商取引法の通信販売の決まりの一部が当てはまらない、と理解しています。個人の会員とで規約を分けるかを確かめます。

### 3.3 アプリの対応

- 規約類（利用規約・特定商取引法に基づく表示・プライバシーポリシー）は、管理画面の「規約類」で入れます。すべてのページの下からリンクしています。
- 返品特約と送料の表示は、「設定」で入れ、トップページに出します。
- **文面の下書きを `docs/10-規約類の下書き.md` に用意しました**（弁護士の確認前）。

## 4. 進め方（おすすめの順番）

| 順 | やること | だれが | 目安 |
|---|---|---|---|
| 1 | 管轄の警察署に、事業の形を説明し、要る許可・届出を確かめる（1.2） | 発注者 | 1〜2週間。許可が新しく要るなら、さらに約40日かかるとされる【要確認】 |
| 2 | 規約類の下書きを、弁護士に見てもらう（2.3・3.2 の確認も一緒に） | 発注者 | 2〜4週間 |
| 3 | 設定に、主催者の住所・電話・メール・古物商の許可を入れる | 主催者管理者 | 10分 |
| 4 | 規約類の正式な文面を、管理画面の「規約類」に入れる | 主催者管理者 | 30分 |
| 5 | 返品特約の仮の文言を、正式な文言に替える | 主催者管理者 | 10分 |
