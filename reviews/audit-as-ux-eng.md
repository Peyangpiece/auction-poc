# UX Audit: オンラインオークションの入札画面

**Perspective**: UX Engineer（audit-as-ux-eng）＋ AI チェッカー（impeccable 4.9.2 の検出器）
**Date**: 2026-11-18
**Plan**: `web/bidder.html`・`web/bidder.css`・`web/bidder.js`（入場 → 参加手続き → 待機 → 入札 → 上回られる → 切断・再接続 → 落札・流札）

前回の点検（2026-11-16、会員登録から落札まで）は、この版で置き換えた。前回の内容は git の履歴にある。

## Plan Summary

会員が、ログインのあと入札画面に入り、参加のしかたを選び、参加手続きを済ませ、品が出たら金額を入れて入札し、結果を知るまで。今回の変更（1円単位の入札、入札・落札の演出）を含めて点検した。

## 点検のしかた

- **AI チェッカー**: 動いているサーバーで、画面の状態（入場・待機・受付中・最高入札者・上回られた直後・流札、PC の最高入札者・落札）を作り、その DOM をチェッカーのブラウザで走査した。スマホ幅（390×844）と PC 幅（1280×800）
- **UX**: 本物の会員（登録・ログイン済み）として、iPhone 13 の幅で、手続きから結果までを操作し、画面を1枚ずつ見た。切断は、端末の通信を12秒切って確かめた。相手の入札は、PC の別の参加者から入れた

## AI チェッカーの結果

| 画面 | 修正前 | 修正後 |
|---|---|---|
| 入場・待機・受付中・最高入札者・上回られた直後・流札（スマホ幅） | 0 件（助言 1: 見出しの段の差が小さい。本文 13px・見出し 15px・品名 18px で、どの段も 1.25 倍に届かない） | 0 件・助言 0 |
| 最高入札者・落札（PC 幅） | 0 件 | 0 件 |
| ソース（bidder.html・css・js、app.css） | 0 件（助言 1: 使っていない、はね返る動きの曲線が残っていた） | 0 件・助言 0 |

## Verdict: APPROVE WITH CHANGES（必須の2件と推奨の3件は、この版で直した）

## Critical Issues (Must Fix)

| # | Issue | Step in Journey | Impact on User | Fix |
|---|-------|----------------|----------------|-----|
| 1 | 参加手続きで選び忘れても、知らせが画面の外 | 3 | 押しても何も起きないように見え、手続きで止まる（入札できない） | 送る前に確かめ、選んでいない欄のすぐ下に出して、その欄へ移る。選んだら消える【直した】 |
| 2 | 1円単位の入札のあと、次の入札額の目安が半端 | 9 | ¥10,100 のような額が欄に入る。そのまま押すと、段より 100円高く入れてしまう | 目安を「現在価格より高い、いちばん近い段」にした（`server/src/ladder.js`）【直した】 |

## Recommendations

| # | Issue | Impact | Fix |
|---|-------|--------|-----|
| 1 | 1円単位で入札できることが、画面から分からない | 新しい決まりに気づかず、目安の額だけで入札する | 欄を押したときに「¥○ 以上、1円単位で入力できます」【直した】 |
| 2 | 見出しの段の差が小さい（AI チェッカー） | 「入札の履歴」が本文と同じ重さに見える | スマホの節の見出しを 17px に（本文との差 1.3 倍）【直した】 |
| 3 | 使っていない動きの曲線（AI チェッカー） | なし（読む人の混乱） | 消した【直した】 |
| 4 | （直す途中で見つけた）案内を、欄から離れたときに消すと、板の高さが変わって「入札」ボタンがずれ、押しそこなう | 入札が送られない | 案内は、次の入札・価格の更新で入れ替わるまで残す【直した】 |

## Nice-to-Haves（手を付けていない）

| # | Suggestion | Rationale |
|---|------------|-----------|
| 1 | 待機中に、次の品の予告（品番・品名）を出す | 待つあいだに、次が分かる（53.2 の提案。発注者の選択待ち） |
| 2 | 流札・他人の落札のときに、自分の入札が届かなかったことを、短い言葉で添える | 「2番 落札」だけでも分かるが、最高入札者だった人には、結果を自分の言葉で伝えたほうがよい |
| 3 | 入札の欄に、目安と最低額の2つのボタン（「＋1円」「次の段」） | 1円単位の入札を、打たずに選べる。ただし押しまちがいの危険が増えるので、実機で試してから |

## Interaction Consistency Check

- 誤りの出し方: 入札の欄（板の中の赤字）・会員登録（欄の下の赤字）と、参加手続き（今回から欄の下）がそろった
- 確かめのダイアログ: 取り消せない操作（大きな金額の入札）だけに使っている。情報を出すためには使っていない
