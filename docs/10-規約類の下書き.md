## 1. 利用規約

### 第1条（目的と適用）
1. この規約は、〔会社名〕（以下「当社」）が運営する「令和の競り」（以下「本サービス」）で行う競り（オークション）への参加と、落札した品物の売買について定めます。
2. 会員は、この規約に同意したうえで、本サービスを利用するものとします。

### 第2条（会員登録）
1. 本サービスを利用するには、会員登録を行い、当社の承認を受ける必要があります。
2. 個人で登録する方は、18歳以上の方に限ります。
3. 当社は、登録の内容に誤りがある場合、過去に規約に違反したことがある場合、そのほか当社が適当でないと判断した場合は、登録を承認しないことがあります。
4. 会員は、登録した内容に変更があったときは、マイページで速やかに変更するものとします。
5. ログイン ID・パスワード・認証の手段は、会員が自分で管理し、第三者に使わせてはなりません。

### 第3条（競りへの参加）
1. 会員は、開催ごとに参加の手続き（受け取り方法と支払方法の選択）を行い、参加番号の割り当てを受けて、競りに参加します。
2. 参加のしかたは、オンライン参加と会場参加があります。会場参加の場合は、会場の受付で来場の確認を受けたあとに入札できます。
3. 当日現金の支払いは、会場参加の方だけが選べます。

### 第4条（入札と落札）
1. 入札は、画面に表示された金額で、品物を買い受ける申し込みです。**入札したあとに、取り消すことはできません。**
2. 進行役が締めた時点で最高入札者であり、かつ、品物ごとの売り切りの条件（「うりきり」の表示）が満たされているとき、その会員が落札者となり、売買契約が成立します。条件が満たされないときは、落札とはなりません（流札）。
3. 通信の遅れなどにより、締めの直前の入札が受け付けられないことがあります。受付の順序と、締めの時点は、当社のサーバーの記録によって決めます。
4. 中継の映像は、実際の会場より遅れて届きます。入札の判断には、画面に表示された価格と状態を用いてください。
5. 当社は、品物の取り違え、機器の故障など、やむを得ない事情があるときは、競りを中断し、取りやめ、またはやり直すことがあります。

### 第5条（代金）
1. 落札者は、落札額に加えて、買歩銭（落札額の〔10〕%）と、配送を選んだ場合の送料を支払います。
2. 銀行振込の場合は、当社が送る請求書に記載したお支払い期限（請求書の発行日の5日後）までに、指定の口座に振り込みます。振込の手数料は、落札者の負担とします。
3. 当日現金の場合は、会場の受付で精算します。

### 第6条（品物の引き渡し）
1. 現地受け取りの場合は、お支払いが確認できた日から7日以内に、当社の指定する場所で受け取ります。
2. 配送の場合は、お支払いが確認できたあとに発送します。送料は、品物の大きさなどにより決まり、請求書で別に請求します。
3. 受け取りの期限を過ぎても受け取らないときの扱い〔保管料・処分の取り扱い：決めること〕

### 第7条（品物の状態・返品）
1. 品物は中古品であり、現状のままお引き渡しします。
2. 落札後の返品・交換は、お受けしません。〔ただし、当社の説明と著しく異なる場合の扱い：決めること〕

### 第8条（支払いがないときの扱い）
1. お支払い期限までにお支払いがないときは、その会員の利用を停止します。お支払いが確認できたときは、停止を解きます。
2. 当社は、お支払い期限を過ぎても支払いがないときは、売買契約を解除することがあります。この場合、会員は、当社に違約金〔金額・計算の方法：決めること〕を支払います。
3. 契約を解除したときは、当社は、次に高い入札をした会員に、その入札額で買い受けるかを打診することがあります。打診を受けた会員は、3日目までに回答します。
4. 期限を過ぎたお支払いについては、遅延損害金〔率：決めること〕を請求することがあります。

### 第9条（禁止事項）
会員は、次のことをしてはなりません。
1. 他人になりすますこと、他人に自分のアカウントを使わせること
2. 支払う意思のない入札、ほかの会員と示し合わせた入札など、競りの公正を害すること
3. コメント欄に、他人を傷つける内容、広告、競りに関係のない内容を書き込むこと
4. 本サービスの運営を妨げること、不正なアクセスを試みること
5. 中継の映像・画面を、当社の許可なく録画・配信・転載すること
6. 法令や公序良俗に反すること

### 第10条（利用の停止・登録の取り消し）
当社は、会員が規約に違反したとき、そのほか当社が必要と判断したときは、事前の通知なく、利用を停止し、または登録を取り消すことがあります。

### 第11条（退会）
会員は、マイページから退会できます。ただし、お支払いが済んでいない落札があるあいだは、退会できません。

### 第12条（お知らせのメール）
1. 当社は、お取引に必要な連絡（登録の承認・請求・落札など）を、登録されたメールアドレスに送ります。
2. 開催のお知らせメールは、受け取ることに同意した会員にだけ送ります。会員は、マイページまたはメールに記載したページから、いつでも受け取りを止められます。

### 第13条（免責）
1. 通信回線・機器の障害、天災その他、当社の責めに帰すことのできない事由により、競りに参加できなかったこと、入札が受け付けられなかったことについて、当社は責任を負いません。
2. 当社に故意または重大な過失がある場合を除き、当社が負う責任は、〔上限：決めること〕を限度とします。〔個人の会員（消費者）には、消費者契約法により無効となる定めがあるため、弁護士の確認が要る〕

### 第14条（規約の変更）
当社は、必要に応じてこの規約を変更できます。変更するときは、変更の内容と効力が生じる日を、本サービスで事前にお知らせします。

### 第15条（準拠法・管轄）
この規約は日本法に従います。本サービスに関して争いが生じたときは、〔地方裁判所〕を第一審の専属的合意管轄裁判所とします。

附則　〔施行日〕から施行します。

## 3. プライバシーポリシー

### 1. 取得する情報
当社は、本サービスで、次の情報を取得します。
- 会員登録の情報: 氏名（ふりがな）、住所、配送先、電話番号、メールアドレス、法人の場合は会社名・ご担当者名・請求先
- 取引の情報: 参加の記録、入札・落札の記録、請求・お支払い・引き渡しの記録
- 本サービスの利用の情報: ログインの記録、接続元の IP アドレス、端末・ブラウザーの種類、操作の記録、コメント

### 2. 利用の目的
1. 会員の本人確認、登録の審査と承認
2. 競りの運営（入札の受付、落札の決定、参加番号の表示）
3. 代金の請求、お支払いの確認、品物の引き渡し・発送
4. お取引に必要なご連絡
5. 開催のお知らせメールの送付（同意した方のみ）
6. 不正な利用の防止と、問題が起きたときの調査
7. 法令に基づく対応（古物営業法による記録など）
8. 本サービスの改善

### 3. 第三者への提供
法令に基づく場合を除き、本人の同意なく、個人情報を第三者に提供しません。

### 4. 取り扱いの委託
当社は、利用の目的の範囲で、次の取り扱いを外部の事業者に委託します。委託先は、適切に管理します。
- サーバーとデータの保管: Cloudflare, Inc.（米国）
- メールの送信: Resend（〔運営会社名・国を確認〕）
- 中継の映像の配信: Amazon Web Services（中継を使う場合）
- 品物の配送: 〔運送会社〕

〔外国にある事業者への提供・委託にあたるため、個人情報保護法の定める情報提供が要るかを、弁護士に確認する〕

### 5. 安全の管理
個人情報への不正なアクセス、漏えいなどを防ぐため、通信の暗号化、アクセスの権限の管理、操作の記録などの措置を取ります。

### 6. 開示・訂正・利用の停止の請求
本人から、個人情報の開示・訂正・利用の停止などの請求があったときは、本人であることを確かめたうえで、法令に従って対応します。お問い合わせ先: 〔窓口・メールアドレス〕

### 7. クッキー
本サービスは、ログインの状態を保つためにクッキーを使います。広告のためのクッキーは使いません。

### 8. 改定
このポリシーを変更するときは、本サービスでお知らせします。

## 4. 弁護士に確かめてほしい点（まとめ）

1. 入札の取り消しができないこと、通信の遅れによる不受付、映像の遅れについての定め（第4条）
2. 免責の上限（第13条）が、消費者契約法で無効にならないか
3. 返品特約と、契約不適合の責任の書き方（第7条・特商法の表示）
4. 違約金・遅延損害金の定め方と金額（第8条）
5. 法人の会員と個人の会員とで、規約を分けるか
6. 入札の前の画面に表示すべき事項（特商法の最終確認画面。`docs/09` の 3.2）
7. 外国の事業者への委託についての表示（プライバシーポリシー 4）
8. 開催のお知らせメールが、特定電子メール法の広告・宣伝のメールに当たるか（`docs/09` の 2.3）
