# 正式リリースの基準の精査（UI・UX）

**日付**: 2026-11-18
**対象**: web/ の全画面（31 ファイル）と、画面に返すサーバーの文言。版 8c7a79d
**使った検査**:
- Web Interface Guidelines（Vercel。最新版を取得）の全ルールで、全ファイルを確認した。
- WCAG 2.1 AA の監査（a11y-eng の観点）。axe で拾えない部分を、キーボード・読み上げ・実測で確かめた。
- UX の監査（ux-eng の観点）。正常でない状態・文言・取り消せない操作を確かめた。
- impeccable（デザインの検出器）で、起動した 11 画面を確認した。
- 既存の自動テスト一式を実行した。

**確かめ方**: 指摘は1件ずつ、該当する行を開いて確かめた。主なものは、アプリを起動して再現した。確かめられなかったものは載せていない。

## 判定: **まだ正式リリースの基準に達していない**

見た目・配色・レイアウト・スマホの収まり・自動の検査は、基準を満たしている。具体的には、次の結果を確かめた。
- axe（明るい配色・暗い配色）: 違反 0
- impeccable: 0
- 幅 320px: 横スクロールなし
- prefers-reduced-motion／transparency／contrast: 対応済み
- 自動テスト: 113 件すべて通過
- 画面の通しの確認・表示の計測: 通過

一方で、次の3種類の問題が残っている。これらを直すまでは、正式リリースの基準に達しない。
- 取り消せない操作に、確認がない。
- 知らせが、出た瞬間に消える。
- 規約類が、仮のままである。

## 推奨（主なもの。重複をまとめて約 25 件）

- **取り消せない操作をそろえる**
  - 進行コンソールの「締め」に確認がない。オークショニア画面では確認しているので、画面によって違う。
  - 繰り上げの打診・明細の確認済み・印鑑の削除・引き渡し・配信の停止に、確認がない。
  - ダイアログの実行ボタンが汎用の「実行する」になっている。操作の名前にする。
  - 退会のダイアログで、最初のフォーカスが「退会する」に当たっている。「やめる」にする。
- **入力が消える**
  - コンソールの「品を追加」は、結果を待たずに欄を空にする（再現済み）。
  - 管理の設定・規約類は、入力したままタブを切り替えると、黙って消える。
- **本日の開催がないとき**
  - コンソールで品を追加すると、開催なしの品ができる（会員から見えない）。
  - 入札画面では、赤字で「本日の開催はありません。」とだけ出て、次の開催への道がない。
- **応答がないとき**
  - オークショニアとコンソールの「応答がありません」だけでは、締めが通ったのか分からない。入札画面には、すでに良い書き方がある。
- **権限のない役割で開いたとき**
  - 戻る道がない。文にある役割の名前も不正確。
- **会場の Wi-Fi で一斉につなぎ直すとき**
  - 同じ IP から 20 本を超えると、「送信が多すぎる」と利用者のせいのように出る。自動でもつなぎ直さない。
- **請求書の振込先**
  - 未設定なら、PDF に「（未設定）」と出る。公開の前に警告を出す。本番では原本の値が入っている前提。
- **読み上げ**
  - コメントの欄が、新しいコメントのたびに全件を読み直す。
  - オークショニア・コンソールで、入札のたびに細切れの読み上げが重なる。
  - 自分が最高入札者でないあいだは、価格の変化が伝わらない。
- **フォーカス**
  - 次の操作のあとに、フォーカスが外れる（実測）。
    - 「参加する」
    - 認証番号の確認
    - 「送り直す」
    - お知らせの切り替え
    - 管理のダイアログの実行
  - 入札画面の Tab の順が、表示の順と逆になる所がある。
  - 履歴・コメントの欄を、キーボードでスクロールできない。
- **上の帯・下の板の下に隠れる**
  - scroll-padding がないため、Tab で進んだ欄が帯や板の下に隠れる。
  - 規約の見出しが、上の帯の下に隠れる。
  - 会員のページで、iPhone を横にすると、ノッチに文字がかかる。
- **言葉**
  - 「権利」を「最高入札」に変える（前回の監査の #5。未対応）。
  - ゆれを直す: 開始値／開始価格、落札価格／落札額、現地受け取り／会場で受け取り。
  - 記録の画面に、英語の内部の名前（staff.setup など）が出ている。
- **重さ**
  - logo.svg（146KB）は、中身が PNG で、全ページで読み込んでいる。暗い配色用にも、同じ大きさのものがもう1つある。軽い SVG か WebP にする。

## 軽微（約 25 件）

次のようなものがある。
- 日付の書き方の統一
- 金額欄で、カーソルが末尾に飛ぶ
- theme-color の色ずれ
- タブの矢印キー操作
- dialog の名前
- autocomplete の細部
- 44px 未満の押せる所。AA の基準外で、PC 向け・「中断」40px
- 開発者向けの記録の言葉

細目は、各検査の報告のとおり。

## リリースできる状態にあるもの

- **見た目**: 配色・余白・文字・暗い配色・リキッドグラス（透明度を下げる設定のときは、不透明に戻る）。
- **スマホの収まり**: オークショニア画面は、5機種の幅で、はみ出し 0。入札画面は、幅 390px で 44px 未満の押せる所なし。幅 320px で横スクロールなし。
- **入札の誤りの文**: サーバーが返す誤りを、すべて言葉にしている。上回られたときは、金額と次の入札額を読み上げる。
- **再接続**: 入札者の再接続の文がある（送信中に切れたときの確かめ方まで出す）。
- **ページの行き先**: ログインしていない人の行き先は、正しい。404 ページもある。
- **画面の状態**:
  - 空の状態: 管理の各タブ・マイページ・コンソール。
  - オークショニア画面の確認: 締め・流札・うりきり。
  - コンソールの取りやめ・除外・開催終了・代理入札の取り消し: 理由を必須にしている。
- **公開版の安全**:
  - 開発用の表示: 本番の設定で、隠れている。
  - 合言葉のログイン: 本番の配布では、無効になっている。
  - 画面のコード: console.log や TODO がない。
